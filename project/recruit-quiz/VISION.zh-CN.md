# aDaptQuiz 愿景

## 目的

`aDaptQuiz` 是依据 aDapt Family Solutions Ltd 在 SJS 发布的 `Computer Tech (online forms)` 职位需求制作的英文界面 prototype。它展示一个小型、清楚、可验证的在线题库与自测流程，同时保留 Cloudflare App Base 已有的认证、数据库、邮件和部署准备能力。

本项目必须明确说明其 prototype 身份和 [SJS 来源](https://www.sjs.co.nz/job-details/2304/computer-tech-online-forms-3628)，不得暗示为 aDapt Family Solutions Ltd 已正式发布或认可的产品。

## 当前版本愿景

当前版本让管理员维护一个简单题库，让已登录用户每轮完成三道随机题目，并立即对照正确答案或参考指导。用户的纯自测内容不保存、管理员不可见；只有用户主动确认时，系统才通过邮件把本轮副本发送给管理员。

## 产品原则

1. 保持简单：每轮只包含选择题、判断题和问答题各一题。
2. 隐私优先：自测答案只存在于当前浏览器页面内存。
3. 用户主动披露：邮件副本绝不自动发送。
4. 真实状态：未配置邮件、题库不足或 Provider 失败时明确降级，不显示虚假成功。
5. 复用基础：继续使用 Better Auth、Hono、D1、Kysely、共享布局和现有邮件 Provider。
6. 不提前建设：不为正式版历史、后台答卷或题目生命周期功能预建空模块。

## 正式版本方向

页面可以说明正式版本将提供：

- 保存和查看用户自己的测试历史；
- 管理员在后台查看用户主动发送的答卷；
- 题目编辑、删除和可用性控制；
- 管理员 UI 设置答卷接收邮箱。

正式版本仍必须保证：管理员不能查看未主动发送的纯自测结果。

## 成功标准

- 英文界面准确说明职位来源、prototype 身份和隐私边界。
- 管理员能新增和查看三种题型。
- 每轮恰好随机抽取三种题型各一题。
- 提交后立即显示用户答案和权威答案，不持久化答题内容。
- 用户能真正开始新一轮。
- 配置完整时，用户可主动通过 Resend 发送答卷副本。
- 所有权限、失败和未实现功能均有真实、清楚的表现。

## 交付边界

本项目位于 `project/recruit-quiz` 分支。未经独立明确授权，不执行 Cloudflare 部署、远程 D1、Secret、OAuth、GoDaddy DNS、Resend 配置、真实邮件测试、付费资源或远程推送。
