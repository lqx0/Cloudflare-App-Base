# 里程碑 6：质量与安全设计

## 目的

为当前本地 Cloudflare-Ankit 应用完成可验证的安全与质量基础审查，不部署、不修改远程资源。

## 安全响应头

- 在 Worker 中添加安全头中间件。
- 生产 CSP 使用同源默认策略，禁止对象嵌入，限制 frame、表单和 base URL。
- 本地开发 CSP 允许 Vite 热更新所需的 `ws:`/`wss:` 连接。
- 不预先添加未配置的 Google、邮件或第三方域名；以后经确认后再扩展白名单。

## 审查范围

- 保留泛化认证错误与 CLI API Key 常量时间比较；不得将密钥、密码、会话或邮箱写入日志。
- 检查 `.gitignore` 与环境文件未被追踪；运行依赖漏洞检查并如实记录结果。
- 为安全头和受 CLI 保护的拒绝行为添加聚焦测试。
- 检查公开页面语义标题、键盘可达链接和窄屏布局；不进行无关 UI 重构。

## 限制与验证

- 不修改 Cloudflare、D1、DNS、OAuth、邮件或远程仓库。
- 运行测试、lint、build、`npm audit` 和本地 HTTP 头检查。
- 每个独立任务验证通过后单独本地提交。
