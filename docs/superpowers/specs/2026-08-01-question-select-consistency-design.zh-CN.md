# 题目下拉组件一致性设计

## 目标

让题型选择便于未来扩展，同时保证题目表单中的所有下拉控件在视觉和行为上保持一致。

## 设计

- 将三个卡片式 `QuestionTypeSelector` 改为使用仓库已有的 shadcn `Select` 组件。
- 保留现有 `value`、`onChange` 和可选 `disabled` 接口。
- 保留现有三个值和英文标签，不新增题型。
- 将判断题正确答案的原生下拉框也改为相同的 shadcn `Select` 组件。
- 保留默认值、条件字段、校验、API 请求结构和数据库行为。
- 不修改 shadcn 组件内部实现。

## 验证

通过 TDD 验证两个字段都使用共享 Select 组件，然后运行聚焦测试和完整项目检查。
